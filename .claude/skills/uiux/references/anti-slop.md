# Anti-slop rules

What makes generated UI look templated, and what to do instead. Apply these while designing; the installed taste and impeccable-style skills go deeper.

1. **No default palette.** No purple-to-blue gradient on white, no neutral grey plus one blue accent by reflex. Derive the palette from the brand and industry, state each colour's role, warm or cool on purpose, and check contrast.
2. **No default type.** Do not set everything in one system or `Inter`-by-default face. Pair a distinctive display face with a readable body face (and a mono for labels or numbers if it fits); state licence and self-hosting.
3. **No card soup.** Not every group of content needs a bordered, rounded, shadowed card. Use rules, colour bands, whitespace and scale to separate. Keep a radius budget.
4. **No symmetric template.** Avoid the centred hero, three equal feature cards, centred CTA, footer pattern. Use asymmetry, offsets and one deliberate grid break per page.
5. **No filler.** No lorem ipsum, no "Welcome to", no three-word value propositions that fit any company. Copy is specific or marked `[CLIENT TO CONFIRM]`.
6. **No decorative emoji or stock icon rows** standing in for design. Icons are consistent in weight and size, and earn their place.
7. **No motion for its own sake.** Every animation has a purpose (arrival, emphasis, transition, spatial continuity) and a reduced-motion variant.
8. **One focal point per viewport.** If two things compete, one loses scale or contrast.
9. **Real states.** Hover, focus, active, disabled, loading, error and empty states are designed, not left to browser defaults.
10. **Accessible by construction.** Visible focus, keyboard order, contrast, `alt` text, form labels and errors. Accessibility is a design input, not an audit at the end.
11. **Performance is design.** Image bytes, font loading, JavaScript weight and 3D cost are decided here and written as budgets.
12. **Name the signature.** Each site has one move people would remember (a scroll sequence, a type treatment, a texture). If you cannot name it, the direction is not finished.
