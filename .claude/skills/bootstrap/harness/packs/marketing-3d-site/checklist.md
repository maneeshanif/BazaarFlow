# Marketing site, cinematic and 3D-forward — checklist

Every item must be answered in the PRD before Phase 1 exits. Each becomes a requirement and a candidate acceptance test.

- [ ] C-M3S-01 Largest Contentful Paint stays within the budget with the 3D or video present; the hero never blocks first paint.
- [ ] C-M3S-02 Every 3D or video element has a static fallback image and loads after first paint.
- [ ] C-M3S-03 A reduced-motion version exists for every page and carries the same content with no scrubbing or autoplay.
- [ ] C-M3S-04 The mobile version replaces pins and horizontal scroll with vertical reveals, and parallax is capped.
- [ ] C-M3S-05 Low-power devices and data-saver mode get the light path (static or poster) instead of the heavy one.
- [ ] C-M3S-06 All text and meaning live in real HTML, not only in a canvas or image, so it can be read, searched and indexed.
- [ ] C-M3S-07 Scroll-driven sections keep keyboard access, anchor links and the browser back button working.
- [ ] C-M3S-08 Only transform, opacity and clip-path are animated; JavaScript for the first route is under the stated budget.
- [ ] C-M3S-09 Fonts load without blocking first paint and without layout shift.
- [ ] C-M3S-10 Forms have spam protection, a success and an error state, and a tested delivery path.
- [ ] C-M3S-11 Title, description, headings, structured data and social share images exist for every page.
- [ ] C-M3S-12 Analytics and cookies follow the consent rules of the target market.
- [ ] C-M3S-13 Legal pages contain real text agreed with the client, not placeholders.
- [ ] C-M3S-14 Contrast passes AA for every text and background pair, including text over video or imagery.
