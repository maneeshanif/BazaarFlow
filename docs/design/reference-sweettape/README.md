# Reference study: sweet-tape.com

Captured 2026-10-21 with Claude in Chrome at 1536px wide. This is a **design reference** for the BazaarFlow public site. We borrow structure, rhythm, colour logic and motion ideas. We do not copy SweetTape's logo, photos, illustrations, product art or copy.

| File | Covers |
| --- | --- |
| `tokens.md` | Colours, type, radii, spacing, motion |
| `layout-and-navigation.md` | Header, nav, footer, page frame, intro transition |
| `page-home.md` | `/` section by section |
| `page-news.md` | `/news` |
| `page-about-products-contact.md` | The other three pages |

## Pages and measured size

| Route | Page height | Notes |
| --- | --- | --- |
| `/` | 14,534px | Longest page; scroll-driven product storytelling |
| `/products` | 1,867px | "Pick your player" product picker |
| `/about` | 12,110px | Pill-shaped scrolling story rows |
| `/news` | 2,907px | Highlight card, filter list, card grid |
| `/contact` | 2,098px | One heading, email and phone, big footer |

## Not captured

Hover states, the "Pull me" ribbon's drag animation, the audio toggle, the mobile layout and individual article pages were not inspected. A pass at 390px width is needed before building mobile.
